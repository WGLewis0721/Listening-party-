# Nova Vale · Listening Room

Static landing page for a monthly listening room. Live page: `site/index.html`.

- Deploys to GitHub Pages through `.github/workflows/pages.yml` on every push to `main`. Only `site/` is uploaded.
- Artist and event copy are placeholders for a fictional artist. Replace them with rights-cleared content before promoting it.
- The page is `noindex` until you remove that meta tag.
- Signup form `action` and streaming links are placeholders and need wiring before launch.


See `HANDOFF.md` for launch steps and the design artifacts in `design/`.
